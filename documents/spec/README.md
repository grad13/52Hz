# spec

Specifications for the 52Hz app — the settled-format contract between code and
tests. Organized to mirror the code tree (`frontend/`, `tauri/`).

## Naming

Source-mirrored names (a spec is named after its `Source` code, e.g.
`timer.md` ↔ `timer.rs`); never date-named.

## Frontmatter

Managed by `set-frontmatter` (run it; do not hand-edit).
